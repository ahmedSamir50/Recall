# Recall

Recall is an on-device multimodal second brain. One .NET 10 MAUI Blazor Hybrid codebase ships to four native shells. v1 is local-only: no server, no accounts, no cloud embedder, no cloud vector database, no web client.

The license is [LICENSE](LICENSE). It is source-available. A commercial use is not granted.

Build and release stay on the developer machine. This repository has no GitHub Actions workflow.

ZVec.NET 1.0.0-beta.6 is not on nuget.org. Restore uses the local feed in the user NuGet config. This repository does not publish that package.
