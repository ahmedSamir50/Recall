# Recall · brand (logo + splash)
Colours from the shader bubbles (`shader.js`: cyan `vec3(0,.949,.996)` = #00F2FE, violet `vec3(.54,.36,1)` = #8A5CFF) plus emerald #67F4B7 from `tokens.css`. Light theme uses the ink versions: #00737A · #6B21A8 · #047857.
The infinity the user liked is Stitch's Material Symbol `all_inclusive` (v0/v1 header); the enhanced prototype had swapped it for a lattice glyph.

## Options
- A · Infinity (enhanced): `svg/infinity-*` — a true Bernoulli lemniscate with lobes opened 28% for optical balance; a single gradient stroke that's ready to animate (pathLength=1).
- B · Loop-r: `svg/loop-r-*` — a lowercase r whose arm becomes half an infinity loop. The memory comes back to you.
- C · Local loop: `svg/local-*` — the infinity inside a device boundary with a node at the crossing. Endless, but kept on this device.
- D · Return node: `svg/return-*` — an open ring whose end comes back to a node. Simplest, best at 16 px.
Per option: `-master.svg` (dark), `-master-light.svg`, `-mono.svg` (currentColor), `-icon-{dark,light}.svg` (1024 tile, rx 228), `-icon-small-*.svg` (tighter crop and thicker stroke for ≤48 px), `-lockup-{en,ar}-{dark,light}.svg`. PNG exports are in `png/` (1024/48/32/16).
Lockups use live text (Space Grotesk / IBM Plex Sans Arabic); outline the text before production use.

## Splash
`splash.html` is double-clickable with no modules. Params: `?theme=dark|light&lang=en|ar&mark=infinity|loop-r|local|return&reduced`.
Timeline: the stroke draws itself 0–1.2 s, the gradient sweeps once 0.25–1.7 s and settles, the wordmark fades in at 0.9 s and the subline at 1.2 s, done at 2.0 s.
Frames are a pure function of time, so there are no flashes. Under reduced motion it shows the final frame with a static shader. Frames are in `frames/`; the video is `splash.mp4`.
