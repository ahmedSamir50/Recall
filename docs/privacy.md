Status: in-code for the ban, open for U3.

## Allowed

Allowed network is the model-weight download only.

## Forbidden

Forbidden: cloud embedder, hosted vector database, accounts, telemetry SDK, crash reporter that phones home, sync transport. Paths stay in the local collection so the UI can open the file. They are not analytics. Checkpoint paths stay on device. No new network path. No information log of a path or file text. Secrets, databases, lock files, and skip folders are not read, including when a gitignore exception names them. Publishing the source is not a network path in the app. Granted files, vectors, and model weights stay off a build runner. A later runner may compile the four shells. The public stub is a README only. This tree has not migrated. The license contact address is the author's published address. It is not a user identifier. The app does not ask for revenue and does not send that address.

## Open

U3: goal is zero telemetry; an opt-in reporter is unresolved; v1 does not add one.
