## Watchers

Every shell diffs the granted reader against checkpoints.db when the window is created and when it resumes. When open replaces `items_text` because its loaded schema has no `fts_key` field, `ResetTextIngest` clears those checkpoint rows first, so the diff reads the granted files again. A parent directory adds one FileSystemWatcher with IncludeSubdirectories on Windows, Mac Catalyst, and a real Android directory. iPhone does not construct FileSystemWatcher. A content:// grant has no live watcher. The loop wakes when a change is reported or a rescan is requested. It does not poll. The change buffer holds at most 64 paths. ScopeWatcherKindPolicy.Choose maps Windows, Android, and MacCatalyst to WindowsFileSystem. Ios and Unknown map to None. DisabledScopeWatcher does not watch. No FileObserver, no background iPhone watch, no FSEventStream call, no ContentObserver. Hiding the window to a tray is not in the tree. Destroying still stops the coordinator.
