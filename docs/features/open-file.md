## Decision

`LocalFileOpenPolicy.Classify` returns `Empty` for null or white space, `ContentUri` when the path starts with `ContentUri.Scheme`, otherwise `Filesystem`. `Decide`: `threw` returns `Failed`; empty probe returns `Failed`; content URI returns `Opened` when `platformAccepted` else `Failed`; missing filesystem returns `Missing`; filesystem returns `Opened` when `launcherOpened` else `Failed`. `Exists` is false for empty, the content-stream flag for a content URI, and the filesystem flag otherwise. Home uses `ILocalFileOpener`. A missing file stays on the card as unavailable. A tombstone stays on the card as unavailable. A code hit opens through the same path because the stored path is the file.

`ILocalFileOpener` also has `OpenAtAsync(sourcePath, startSeconds)`, which carries the seek intent but the Maui launcher cannot start mid-file, so its implementation defers to `OpenAsync` without reading the seconds. A hit whose start is above zero therefore opens in the app instead: `MediaHitStart.Seconds` reads `TextSearchHit` or `MediaSearchHit`, `MediaHitStart.Seeks` is true only when the start is greater than zero, and Home calls `IMediaPreview.PlayAsync(path, startSeconds)`. The Maui implementation pushes a `MediaPreviewPage` that plays the file in `CommunityToolkit.Maui.MediaElement` and, on opened, seeks to that many seconds. A start of 0 still uses the launcher.
